## Repository Structure

```text
src/
├── generate_dataset.py
├── train_model.py

dataset/

```

## How to Run

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Generate Dataset

```bash
python generate_dataset.py
```

### Train Model

```bash
python train_model.py
```

### Predict Modulation

```bash
python predict.py
```
